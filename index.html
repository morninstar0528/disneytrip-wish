Firebase 連線排除教學

請對照以下 Firebase 後台步驟檢查：

1️⃣ 是否開啟「匿名登入」？

進入 Firebase Console -> Authentication -> 登入方法 -> 找到「匿名」並開啟儲存。

2️⃣ 是否已建立「Firestore Database」？

進入 Firestore Database -> 點擊「建立資料庫」-> 選擇「以測試模式啟動」。

3️⃣ 安全性規則是否被拒絕？

至 Firestore 的「規則」頁面，確定開放讀寫權限 (`allow read, write: if true;`) 並點擊「發布」。
